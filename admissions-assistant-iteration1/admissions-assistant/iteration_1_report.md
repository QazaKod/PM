## 1. Iteration Overview
In the first iteration, we created the basic features for the Smart Admissions Assistant. We focused on the main User Stories: answering questions about study programs (US1) and frequently asked questions (US5). We also started the basic logic for program recommendations (US2).

We built a **Hybrid AI Engine**. It uses a fast local search for simple questions. If a question is too difficult or unusual, it uses **Google Gemini (3.6-flash)** as a fallback.

---

## 2. Completed User Stories

### ✅ US1: Chat-Program Info (Story Point: 4)
> **As an applicant**, I want to ask the chatbot questions about educational programs, so that I can quickly get information about available programs.
*   **Result:** We created a database file called `programs.json`. The chatbot can understand questions about program cost, duration, format, and UNT subjects.
*   **Constraints:** The chatbot only uses official and current university data.
*   **Fallback system:** If the chatbot is not sure about the answer, it sends the question to the Gemini AI. It also shows an "Admissions Staff Offer" badge to warn the user that the answer is generated by AI and gives a way to contact the real university staff.

### ✅ US5: Admission FAQ (Story Point: 2)
> **As an applicant**, I want to get answers to frequently asked admission questions, so that I don't have to search for information manually.
*   **Result:** We created a search module for the `faq.json` database. The chatbot can quickly answer questions about deadlines, documents, and procedures.
*   **Constraints:** We added a UI accordion to read the FAQ easily. If the question is not in the FAQ base, the system tells the user and offers to connect them with the staff.

### 🟡 US2: Program Recommendation (Basic setup)
> **As an applicant**, I want to receive program recommendations based on my interests and academic goals.
*   **Result:** The Gemini AI module can give basic recommendations. For example, if a user writes *"I like math and business"*, the AI looks at the SDU programs and recommends a ranked list (like Finance or Information Systems).
*   **Next Steps:** To finish this story, we need to create a short questionnaire dialogue to collect the applicant's interests.

## 4. Technical Results

1.  **Architecture**: We built a full backend using FastAPI (`api.py`, `chatbot.py`, `database.py`).
2.  **Hybrid Router**: We added a Confidence Score. If the score is `< 0.35`, the system asks the Google Gemini AI.
3.  **UI/UX (Frontend)**:
    *   We made a Single Page Application (SPA). Pages change without reloading.
    *   **Dynamic Themes**: We created three designs (Steppe, Metro, Festival). You can change them quickly in `config.json`.
    *   We used professional SVG icons (Phosphor Icons). We removed emojis to make the site look serious.
    *   *Note: We temporarily hid US4, US8, and US9 from the menu as requested.*
4.  **Start Script**: We created a `start.bat` file. Now you can start the server in one click.
